# 😭 Documentation

Documentation will come slowly but below is instructions for how to set stuff up when you are contributing.

If you have questions, feel free to ask in our Discord server:

https://discord.gg/YtQdrkxfg7

## Checklist
- [ ] Make a discord bot and copy the token
- [ ] Set up the .ini file
- [ ] Set up the assets folder
- [ ] Run the bot.py file


## Setting up the .ini file

Make a file named "config.ini" with the following
```ini
[DEFAULT]
TOKEN=INSERT_BOT_TOKEN
TEST_GUILD_ID=INSERT_YOUR_GUILD_ID
TOPGG_TOKEN=not_valid_dont_worry_about_this_its_just_needed
PXSL_API_KEY=not_valid_dont_worry_about_this_its_just_needed
OWNER=INSERT_YOUR_ID
TESTING=True
```

## Setting up the assets folder

Make a folder named "assets" with the following:
- A folder named "default"
 - Inside the folder named default, add two **PNG** files, one called avatar and one called banner

Add information for TOKEN (the token to your discord bot), TEST_GUILD_ID (the guild id of your server, if you don't know how to get this... you probably shouldn't be here.), OWNER (put in your discord id)
